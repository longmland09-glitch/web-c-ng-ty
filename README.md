# Company Website

Mã nguồn website công ty.

## Cấu trúc

- `may-moc.html` — trang Máy móc: ảnh thực tế và mô hình 3D (three.js, tải từ CDN jsDelivr) của từng máy.
- `assets/js/machine-3d.js` — dựng mô hình 3D theo kích thước lắp đặt (mm).
- `assets/img/may-moc/` — ảnh thực tế của máy, ví dụ `mv1200s-photo.jpg`.

- `.claude/skills/frontend-design/` — skill thiết kế giao diện cho Claude Code (nguồn: anthropics/skills).
- `.claude/skills/ui-ux-pro-max/` — skill tra cứu style, bảng màu, font, quy tắc UX (nguồn: nextlevelbuilder/ui-ux-pro-max-skill, bản 2de1134). Đã sửa đường dẫn script trong SKILL.md thành tương đối với gốc repo.
